This is a problem encountered when creating native methods for RexxUnicodeServices


# A native method of class C cannot call a private method of class C

-- The native utf8StringUnescape method cannot call a private method when the native method is called outside an ooRexx method context.
-- Workaround:
--     - Call the native utf8StringUnescape method from an ooRexx method of RexxUnicode.
--     - Make the native utf8StringUnescape method private.

## Minimal test case
::class C subclass native_C
::method m1 class private
::method m2 class
    self~m1

say .C~m2
-- no error

The ooRexx `m2` method is ported to C++ under the name `native_m2`.

class native_C : public RexxObject {...}
void native_C::native_m2
{
    ProtectedObject result;
    self->messageSend(GlobalNames::M1, OREF_NULL, 0, result);
}
CPPM(native_C::native_m2),
StartClassDefinition(native_C)
        AddClassUnguardedMethod("native_m2", native_C::native_m2, 0);
    CompleteClassMethodDefinitions();
    CompleteMethodDefinitions();
    CompleteClassDefinition(native_C);
EndClassDefinition(native_C);

say .C~native_m2
-- Object "The C class" cannot accept private message "M1" from this context

RexxObject::checkPrivate
This error occurs because activation->getReceiver() == OREF_NULL
The activation is the one of `say .C~native_m2`, we are not in the context of an ooRexx method of C.


The `receiver` is set when running some ooRexx code.

## Real test case - C++ implementation

The native method utf8StringUnescape is implemented on RexxUnicodeServices.
The C++ implementation is a port of the ooRexx implementation of stringUnescape.
The RexxUnicode class inherits this native method.

```C++
class RexxUnicodeServicesClass : public RexxObject
{
    RexxObject *utf8StringUnescape(RexxString *string, MutableBuffer *destination);
}

utf8proc_int32_t codepointFromName(RexxObject *self, RexxString *name)
{
    RexxObject *args[1];
    args[0] = name;
    ProtectedObject result;
    self->messageSend(GlobalNames::CODEPOINTFROMNAME, args, 1, result);
    return ((RexxObject *)result)->integerValue(9)->getValue();
}

RexxObject *RexxUnicodeServicesClass::utf8StringUnescape(RexxString *string, MutableBuffer *destination)
{
    ...
    codepoint = codepointFromName(this, name);
    ...
}
```
