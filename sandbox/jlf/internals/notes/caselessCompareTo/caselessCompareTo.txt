I did not apply the fix proposed by ChatGPT.
I fixed the problem by modifying rgf_util2.rex to replace a simple object~string
by a call textOrString(object).

:routine textOrString private
    use strict arg object
    if object~hasMethod("text") then return object~text
    return object~string
